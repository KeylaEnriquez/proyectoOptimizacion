# Proyecto de Optimización

Este repositorio contiene la implementación de los algoritmos en Python para el proyecto final.

## Estructura del Repositorio
* `src/`: Contiene los códigos fuente de los algoritmos (Multiprocesamiento, Greedy, 2-opt, Recocido Simulado y MST).
* `docs/`: Contiene el reporte final en PDF y las gráficas generadas en las pruebas.
